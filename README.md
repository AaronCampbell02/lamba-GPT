# lamba-GPT
This project is an interactive terminal text parser built in Haskell to interpret natural language commands

features:

Maths: what is 2 plus 2? (supports plus/minus/times)
can you use that to reference previous results e.g.
what is that times 5?

Date
What day is it?
What day is it tomorrow?
How long ago was 2020-01-01?

Remember that xyz is ...
tell me about xyz.

memory is non-volatile so persistent over separate times the program is run 

Jokes:

Tell me a joke about (category)

a category on official jokes api (https://github.com/15Dkatz/official_joke_api)

Games:

Play RPS with (rock/paper/scissors).

Can be run by
```runghc TUI.hs```
